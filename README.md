# StockRoom: Inventory Management System
BSE 4103 Advanced Internet Programming, progressive coursework (Weeks 1-4 complete).

## Run locally
    npm start        # http://localhost:3000

## Features by week
- Week 1: Home, About, Services, add-stock form, navigation; Git + deployment
- Week 2: Semantic HTML5, external CSS, mobile-first Flexbox/Grid, media queries at 768px and 1024px, viewport meta, responsive nav/cards/form/table/footer
- Week 3: ES6+ and async/await Fetch to DummyJSON (supplier catalogue), loading and error states with retry
- Week 4: DOM selection/creation, event listeners, full form validation with inline messages, blocked invalid submit, live stock list with search, filter, +/- adjust, delete (localStorage until the Week 5 server)
